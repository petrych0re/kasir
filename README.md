# Kasir Sembako

Aplikasi kasir desktop offline untuk Windows, memakai Tkinter dan SQLite.

Fitur: data produk, barcode scanner USB mode keyboard, keranjang belanja, pembayaran tunai dan kembalian, stok otomatis berkurang, struk TXT, riwayat transaksi, ekspor CSV.

Build Windows berjalan otomatis saat ada push ke branch main. Unduh artifact KasirSembako-Windows-Portable pada tab Actions. Ekstrak ZIP dan jalankan KasirSembako.exe. Pertahankan seluruh isi folder hasil ekstrak.

Database lokal berada di samping aplikasi. Versi ini adalah build dasar; uji transaksi dan printer pada komputer toko sebelum digunakan operasional.
